# Pwalugu Geospatial Explorer

An interactive geospatial dashboard for exploring water resources and environmental conditions in the Pwalugu area and White Volta Basin, Ghana.

## Overview

Pwalugu Explorer brings together geospatial datasets and interactive mapping tools to support spatial analysis and exploration of the project area. The dashboard was developed using Google Earth Engine.

## Live Application

**[Launch Pwalugu Explorer](https://pwalugu-explorer.pages.dev/)**

## Technology

- Google Earth Engine (JavaScript) for geospatial analysis and dashboard development
- HTML and CSS for embedding the application
- Cloudflare Pages for web hosting

## Repository

This repository contains the HTML wrapper used to display the published Google Earth Engine application. The underlying analytical workflows and dashboard source code are maintained separately.

**The full Google Earth Engine JavaScript source code is available upon reasonable request to the author, subject to applicable data access and sharing restrictions.**

## Notes

The dashboard is intended for geospatial exploration and analysis.
